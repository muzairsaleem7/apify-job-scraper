Job Scraper

Job Scraper is a personal, open-source tool that finds remote Full Stack developer jobs on public job boards, scores each one for fit, and saves the results as CSV files and, if you choose, as spreadsheets in your own Google Drive.

How it works

  • It runs only on your own computer. You start it with npm start and use it in your browser at http://127.0.0.1.
  • It collects public job listings from LinkedIn, Indeed, Glassdoor and Wellfound (through Apify) and from RemoteOK, Jobicy, We Work Remotely, Working Nomads and Arbeitnow.
  • When you connect Google, it creates a Job Scraper folder in your Drive with one spreadsheet per run and a Job Tracker spreadsheet, where you track each application with a status dropdown.

Google access

The app asks for one Google Drive permission, drive.file: “See, edit, create, and delete only the specific Google Drive files you use with this app.” It cannot see or change any other file in your Drive. It also reads your email address to show which account is connected. You can remove access at any time at myaccount.google.com/permissions.
